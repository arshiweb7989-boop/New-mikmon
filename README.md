# New Mikhmon

Android MikroTik Hotspot Manager for RouterOS v6/v7.

Current build includes:
- Router IP/host, API port, username/password
- Native MikroTik API connection on port 8728
- Hotspot user listing
- Active/online user listing
- Add hotspot user / voucher
- Speed, data and time limits
- Bulk generation of 10 vouchers
- Enable, disable and delete users

GitHub Actions builds `New-Mikhmon-debug.apk` automatically.

Note: API-SSL (8729), custom voucher templates, package editor and larger configurable bulk batches are reserved for the next release.
